# 일본어 번역 용어집 · 애매한 항목 (D41)

일본어(`frontend/messages/ja.json`) 번역 중 **뜻이 한 가지로 정해지지 않거나, 게임·커뮤니티에서 쓰는 표기가 따로 있을 수 있는 것**을 모았다.
"현재 번역"은 임시이므로, 일본 GITADORA 커뮤니티에서 실제로 쓰는 표기로 확인해 바꾸면 된다. 바꿀 때는 `ja.json`만 고치면 된다(코드 수정 없음).

번역 작업을 하면서 이 표를 계속 채운다.

| 한국어 | 현재 일본어 | 애매한 이유 / 확인할 것 |
|---|---|---|
| 서열표 | 難易度表 | **확정(2026-10-20)**: 일본어를 아는 분이 `難易度表`를 고름(처음 번역은 `序列表`). `ランク表`도 후보였음 |
| 레이팅 상수 난이도 | レーティング定数難易度 | 위 서열표의 기준 난이도를 가리키는 말. `定数`만 쓰는지, `譜面定数`인지 확인 |
| 서열표 정보 제공·설계 (푸터) | 難易度表（レーティング定数難易度）の情報提供・設計: | 사용자가 직접 정한 문구라 한국어는 그대로 두고, 일본어는 위 두 용어에 따라 바뀜 |
| 건의 | ご意見 | `要望`(요청), `ご意見・ご要望`, `フィードバック` 중 어느 쪽이 자연스러운지 |
| 공지 | お知らせ | 거의 확정(`お知らせ`가 표준) |
| 유저 (메뉴) | ユーザー | `プレイヤー`가 게임에서는 더 자연스러울 수 있다 |
| 설명서 | ガイド | `使い方`, `ヘルプ`, `説明書` 중 어느 쪽이 맞는지 |
| 더보기 | その他 | `もっと見る`(더 보기)와 `その他`(기타) 중 선택. 메뉴 모음이라 `その他`로 했다 |
| 최근 플레이 가져오기 | 最近のプレーのインポート | **확정**: `インポート`로 통일(북마크 이름 `SRP インポート`와 맞춤). `取り込み`는 쓰지 않는다 |
| 다시 시도 | もう一度試す | `再試行`이 더 짧고 흔하다. 버튼 폭을 보고 결정 |
| 비공식 팬 프로젝트 | 非公式ファンプロジェクト | 거의 확정. `非公式ファンサイト`도 가능 |
| 단일 / 복합 / 이중 / 삼중 (속성) | 単色 / 複合 / 二色 / 三色 | **확정(2026-10-21)**: 일본 커뮤니티 표기를 따라 `単色`·`二色`·`三色`로 쓴다. `複合`은 그대로. 설명 문장도 `コード`를 붙이지 않고 `単色`, `二色・三色`만 쓴다(`単色で構成された譜面`, `二色・三色で構成された譜面`) |
| 레이팅 제외 (속성) | レーティング除外 | `対象外`가 더 자연스러울 수 있다 |
| 추천도 상 / 중 / 하 | 高 / 中 / 低 | `おすすめ度`의 단계 표기. 서버 값은 한글(`상/중/하`) 그대로 두고 화면 글자만 바꿨다 |
| 슈랜플 (난이도) | スラプラ難易度 | **확정**: 한국 약칭 `슈랜플`에 맞춰 일본어 약칭 `スラプラ`로 쓴다 (레이팅 점수표 안내·캡션·열 제목) |
| 최근 플레이 | 最近のプレー | `最近のプレー`로 통일했다(전에는 `直近プレイ`가 섞여 있었다). 공식 사이트의 실제 표기 확인 필요 |
| 가져오기 화면의 공식 사이트 메뉴 이름 (`chipMain`, `chipPlayData`, `chipHistory`) | メイン画面 / 上部のプレーデータ / 左サイドバーのプレー履歴 | **공식 사이트의 실제 일본어 메뉴 이름으로 확인해야 한다.** 한국어 문구를 직역한 것이라 틀릴 수 있다 |
| 가져오기 북마크 이름 | SRP インポート | 브라우저 북마크 바에 보이는 이름. 짧아야 하고 일본어 사용자가 알아보는지 확인 |
| 북마클릿 번역 안내의 `原文を表示` | 原文を表示 | 번역 안내 문구의 버튼. `元の文を表示`도 가능 |
| 가이드의 가져오기 설명 이미지 | (이미지는 한국어 그대로) | 스크린샷 안의 글자는 번역하지 않았다. 일본어 스크린샷이 필요하면 다시 찍어야 한다 |
| 개인정보 처리방침 | プライバシーポリシー (일본어 번역본) | **법률 검토가 필요하다.** 일본 개인정보보호법(APPI) 용어와 맞는지, 한국 법 기준 문구가 그대로 번역돼도 되는지 확인 |
| 개인정보 처리방침: 쿠키 항목 | 쿠키 2종(로그인 유지 + 언어 `srp.locale`) | 언어 쿠키를 추가하면서 문구가 바뀌었다. **시행일은 그대로 두었다. 시행일을 새로 정할지 결정이 필요하다** |
| 건의 상태 (접수 / 확인 중 / 처리 완료 등) | 受付 / 確認中 / 対応済み | 상태 이름. `処理済み`, `完了`와 비교 |
| 건의 종류 (곡 추가 / 개선사항 / 버그 제보 / 기타) | 曲の追加 / 改善案 / バグ報告 / その他 | `改善案` vs `改善要望` |
| 세트리스트 | セットリスト | 거의 확정. 담기(`追加`) / 완료(`完了`) 동사 확인 |
| 재킷 | ジャケット | 거의 확정 |
| 관리 화면 전체 (ROOT·ADMIN 전용) | 일본어로 옮겼다 | 일본어 사용자가 볼 일이 거의 없다. 설정 이름·설명은 한국 운영자가 읽는 용도라 품질 우선순위가 낮다 |
| 서버가 직접 쓴 오류 문구 (예: 닉네임 중복) | (한국어 그대로) | 서버의 고정 문구 15종(`ErrorCode`)만 번역된다. 서비스가 상황에 맞춰 쓴 문구와 입력 항목별 오류(`fieldErrors`)는 서버 문구가 그대로 나온다. 일본어까지 하려면 서버가 `code`별 상세 코드를 내려야 한다 |
| 웹 앱 설명 (`manifest.ts`의 `description`) | (한국어 그대로) | 설치 화면에 보이는 짧은 설명. 정적 파일이라 언어를 고르지 못한다 |
| 로그인 버튼 (Google) | Google 제공 버튼 | 버튼 글자는 Google 스크립트가 브라우저/지정 언어로 그린다(`locale` 옵션으로 맞췄다) |
