## 2. 주요 결정

### 2.1 개발 환경 (오전)
- **Flyway는 유지**하되 첫 배포 전까지는 `V1__init_schema.sql`을 직접 고친다. 로컬 DB는 `docker compose down -v`로 초기화한다.
- 로컬 DB는 Docker로 쓴다 (MySQL 8.4, 앱 전용 계정 `srpfreaks`, 포트는 내 컴퓨터에서만 접근).
- 컬럼 이름 규칙: PK는 `{테이블 단수형}_id`, FK는 같은 이름. 시간은 모두 `DATETIME(6)` UTC.
- 초출 버전이 갈리는 6곡은 **가장 이른 버전으로 통일** (곡 단위 `songs.added_version` 하나만).

### 2.2 스킬 계산 방식 변경 (D18)
- 공식 사이트에서 기록·곡 목록을 가져오는 기능(확장 프로그램, 북마클릿, 가져오기 토큰, `official_records`)을 **전부 보류**하고 설계 원문은 `DESIGN.md` 18.4로 옮겼다.
- 레이팅은 스프레드시트의 상수표(✋ 기준 난이도) 수식으로 직접 계산한다. 수식 사용은 제작자에게 허락받았다.
  - `R = ✋ > 6.0 ? 5×✋ − 15 : 10×✋ − 45`
  - `V = R × min(A,80)/100 + 3.2 × min(max(A−80,0),15)/15`, 화면 점수 = `V × 20`
- 레이팅 목록은 **SRN+ 하나**, **단일 15 + 그 외(복합·이중·삼중) 25 = 40채보**. 곡 중복 제거는 하지 않고 채보 단위로 센다. HOT은 없앴다.
- ✋이 없거나 서열표에 없는 채보, 속성이 빈 채보(`레이팅 제외`)는 레이팅에서 빼고 기록만 남긴다.
- 플레이어 티어는 합계(정수부)로 20단계 (0, 500, 1000 … 9500). 구간은 `player_tiers` 테이블에 두어 코드 수정 없이 바꾼다. 구간은 1~499 / 500~999 로 정정했다.

### 2.4 재킷 이미지 (D21)
운영자가 곡 재킷을 수집해 쓰기로 했다. 다른 사이트가 쓴다고 해서 권리자 허락이 생기는 것은 아니므로 **위험을 알고 쓰는 선택**으로 기록했다. 완화책은 설정 `ui.show_song_images`로 언제든 끌 수 있게 하고, 외부 주소 직접 불러오기는 하지 않고, 삭제 요청이 오면 즉시 내리는 것이다. (법률 자문 아님)

## 5. 겪은 문제

- **Docker 미실행 / `.env` 없음**: Docker Desktop 실행, `.env`를 만들어 `DB_ROOT_PASSWORD`, `DB_PASSWORD` 설정.
- **3306 포트 사용 불가**(`forbidden by access permissions`): 호스트 포트를 3307로 변경.
- **`.git/index.lock` 잔존**: 중단된 git 작업의 찌꺼기. 삭제 후 커밋.
- 시안 높이 계산이 `sc-if`를 무시하던 문제는 렌더러를 고쳐서 해결했다.
